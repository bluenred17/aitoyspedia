prompt: |
  Pilih salah satu prompt di bawah ini, hapus sisanya, lalu ganti bagian dalam kurung kurawal.

  31. Mentor Coding
  Bertindaklah sebagai senior software engineer sekaligus mentor saya. Review kode saya: {kode}. Temukan masalahnya, jelaskan mengapa masalah itu penting, dan sarankan perbaikan tanpa menulis ulang semuanya.

  32. Debug Kode Saya
  Debug kode ini: {kode}. Temukan masalah yang tepat, jelaskan akar penyebabnya, tunjukkan kode yang sudah diperbaiki, dan jelaskan bagaimana saya menghindari kesalahan yang sama.

  33. Belajar Bahasa Pemrograman
  Ajari saya {bahasa} dari pemula mutlak sampai developer siap kerja. Fokus pada coding praktik, latihan, proyek, debugging, dan pengembangan dunia nyata.

  34. Latihan Wawancara Coding
  Berikan soal wawancara coding untuk {bahasa}/{topik}. Mulai dari yang mudah dan naikkan tingkat kesulitannya secara bertahap. Jangan tunjukkan solusinya sebelum saya mengirim jawaban saya.

  35. Bangun Proyek Nyata
  Bantu saya membangun {project} dari nol. Pertama buat arsitektur dan milestone, lalu pandu saya melalui setiap langkah implementasi tanpa membuat saya kewalahan.

  36. Code Review
  Review kode ini seperti senior engineer: {kode}. Periksa keterbacaan, performa, keamanan, kemudahan pemeliharaan, kasus tepi (edge case), dan praktik terbaik.

  37. Jelaskan Pesan Error
  Jelaskan error ini dengan bahasa sederhana: {error}. Beri tahu penyebabnya, cara memperbaikinya, dan cara mendiagnosis error serupa di masa depan.

  38. Refactor Kode Saya
  Refactor kode ini agar lebih mudah dibaca, dipelihara, dan berperforma baik: {kode}. Fokus pada: {fokus}. Jelaskan setiap perubahan yang berarti.

  39. Latihan System Design
  Berikan masalah system design yang cocok untuk developer level {level}. Biarkan saya mengusulkan solusi lebih dulu, lalu review arsitektur saya dan identifikasi masalah skalabilitas, keandalan, dan performa.

  40. Bangun Proyek Coding Saya
  Berikan 10 ide proyek dengan tingkat kesulitan meningkat untuk mempelajari {teknologi}. Untuk setiap proyek, sertakan fitur, konsep yang dilatih, dan hal yang membuatnya layak masuk portofolio.
---

Kumpulan 10 prompt coding. Tiap prompt berdiri sendiri: salin seluruh isi, hapus sembilan prompt yang tidak dipakai, isi bagian `{...}`, lalu tempel kode atau pesan error yang dimaksud.
